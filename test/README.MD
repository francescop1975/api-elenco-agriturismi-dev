# 🚀 Test per PDND Interoperabilità

Questo repository contiene la collezione di test **Bruno** per i proxy Apigee integrati con la piattaforma **PDND Interoperabilità**.

La collection è configurabile e gestisce le seguenti modalità di ottenimento del Voucher PDND:
-  **Bearer (versione base)**
-  **DPoP (versione base)**

Inoltre è possibile attivare il pattern di sicurezza INTEGRITY_REST_02.

> [!TIP]
> 
> **Maggiori informazioni:** La guida completa è disponibile nella documentazione presente nella Overview della Collection stessa.

----------

## 📋 Prerequisiti

Per utilizzare questa collezione, è necessario installare l'interfaccia corretta:

1.  **Scarica Bruno**: [usebruno.com](https://www.usebruno.com/downloads) (disponibile per Windows, macOS e Linux).
    
    -   _Nota: A differenza di Postman, Bruno salva le richieste come file fisici `.bru` all'interno delle cartelle del filesystem._
        
----------

## 📂 Come aprire la Collection

Per visualizzare correttamente le richieste e gli script associati, segui questi passaggi:

1.  Apri l'applicazione **Bruno**.
    
2.  Nella barra laterale sinistra, clicca su **"Open Collection"**.
    
3.  Seleziona la **cartella radice** (root) del repository che hai appena clonato.
    
4.  La collezione apparirà nell'elenco con tutte le richieste caricate.
